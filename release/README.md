# DataSet Tracker -- prebuilt application

This folder contains the DataSet Tracker application (Windows).

**To run it:**
1. Unzip `DataSetTracker_v1.1.zip`.
2. Place `EBTracker.exe` inside the unzipped `DataSetTracker_v1.1`
   folder.
3. Double-click `EBTracker.exe`.

No installation is required. On launch, it runs a default test video
(located in `EBTracker_Data/Streaming assets` inside the unzipped
folder). To analyze your own video, replace the default one or select a
new file from within the app.

See the root [README.md](../README.md) for background on what this
software does, and [DEPENDENCIES.md](../DEPENDENCIES.md) if you want to
build from source instead of running this prebuilt application.
